# Illustrative sample photos

These four JPEGs were generated using Google Gemini. Their original files contain Google Generative AI provenance data and SynthID watermarks. They depict fictional properties and are not photographs of actual listings.

Optimized to 800px width for the examples. Keep the AI-generated sample captions when reusing them; replace them with verified listing photos for real properties. The build also ships them under `dist/gallery/img/`.
