# Geographic fixture

Chicago community area boundaries downloaded on 2026-10-07 from the City of Chicago:
https://data.cityofchicago.org/resource/igwz-8jzy.geojson

Dataset: https://data.cityofchicago.org/d/igwz-8jzy
Terms: https://www.chicago.gov/city/en/narr/foia/data_disclaimer.html

The local snapshot retains geometry and community names only; coordinates are rounded to five decimal places to reduce size. It is a display reference, not a survey or current legal boundary guarantee. Property markers and prices in the example are fictional. The data is used only in the documentation fixture, not distributed in the design package.
