Install

Install a pinned release. dist/ is committed, so nothing builds on install.

Copy node_modules/@uniform/design/dist/ to your static directory, keeping its structure (CSS references fonts by relative path), and link the stylesheet:

Not using npm? Download dist/ from a tag and check each file against dist/manifest.json.

Usage

Put u-root on the body and compose with native elements. Dark is the default; set data-theme="light" on any element to switch it and everything inside.

For your own components, use the theme variables and the spacing and radius tokens:

Color

The brand palette, from tokens/tokens.json. It's also available as JavaScript (@uniform/design/tokens) and Python. Consumers never hard-code hex values.

Theme variables

Build with these, not the palette. They switch with the theme, so each swatch below changes when you switch between dark and light.

Type

Two self-hosted families under the SIL Open Font License. No font CDN.

Releases

Every vX.Y.Z tag becomes a GitHub Release once the full checks pass, with notes, the npm tarball, SHA256SUMS and a signed build-provenance attestation. Upgrade on purpose: change the pinned tag, read the changelog, then test.
