Get started

Install a pinned release. dist/ is committed, so nothing builds on install. 

npm install --save-exact github:UniformRealEstate/design#v{{version}}

Copy node_modules/@uniform/design/dist/ to your static directory, keeping its structure (CSS references fonts by relative path), and link the stylesheet: 

<link rel="stylesheet" href="/design/design.css" />

Compose with plain HTML. Dark is the default; set data-theme="light" on any element for light. 

<body class="u-root">
  <main class="u-panel">
    <h1 class="u-title">Your workspace<span class="u-dot" aria-hidden="true"></span></h1>
    <p class="u-lede">A clear place to begin.</p>
    <a class="u-button" href="/records">View records</a>
  </main>
</body>

Not using npm? Download dist/ from a tag and check each file against dist/manifest.json.

Components

Plain u-* classes on native elements, with no framework or component JavaScript. The gallery shows each one with working markup, in both themes.

Need Classes
Typography u-title u-heading u-eyebrow u-lede u-meta u-code
Surfaces and messages u-panel u-panel--accent u-callout u-callout--danger u-empty
Actions u-button u-button--quiet
Forms u-field u-select u-hint
Structured information u-facts u-facts--stacked u-table
Status u-tag u-tag--ok u-tag--warn
Navigation and accessibility u-nav u-skip u-sr
Brand details u-dot u-atmosphere

A scrolling u-table wrapper needs tabindex="0" role="region" aria-label="…" so keyboard users can reach it. The brand dot is always u-dot, never a typed period.

Atmosphere

The optional wave motif: one implementation for the animated canvas and for static SVG.

<canvas id="atmosphere" class="u-atmosphere" aria-hidden="true"></canvas>
<script type="module" src="/design/atmosphere.js"></script>

It pauses for reduced motion and hidden tabs. For SVG output, pass only trusted values.

Assets

Brand marks ship in dist/svg/, fonts in dist/fonts/. Use the on-dark variants on dark surfaces.

Releases

Every vX.Y.Z tag becomes a GitHub Release once the full checks pass. Each release has notes, the npm tarball, SHA256SUMS and a signed build-provenance attestation. Upgrade on purpose: change the pinned tag, read the changelog, then test. 

gh attestation verify uniform-design-{{version}}.tgz -R UniformRealEstate/design
